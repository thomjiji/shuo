# shuo

> 本项目仅供我个人使用，它的生命周期直到豆包输入法推出 Windows 版的那一天为止。因为那时候我就跑去用豆包输入法 Windows 版了。

Windows 原生 WinUI 3 听写应用，支持本地模型、豆包和百炼云端流式识别。按全局快捷键开始录音，再按一次停止，最终文本会粘贴到原前台输入框。

从 [最新 Release](https://github.com/thomjiji/shuo/releases/latest) 下载带版本号的 `Shuo-版本-win-x64-Setup.exe` 安装。以后从开始菜单启动“说”，无需保留下载的安装器。已有便携版用户先从托盘退出旧程序，再安装；原配置、凭据和历史会继续使用。详见[安装指南](docs/setup.md)。

## 使用

1. 启动应用。左侧导航分为“常规”“转录服务”“转录历史”和“文本整理”，窄窗口下收起为图标栏。
2. 如需修改快捷键，在“常规”页点击“录音触发快捷键”右侧的铅笔图标，在卡片内按下新组合键并保存。默认 `Ctrl+Alt+\`；清除会禁用全局快捷键。
3. 在普通权限应用的输入框中按一次快捷键开始录音，再按一次停止。
4. 转写完成后，文本会自动粘贴。

标题栏和“常规”页显示当前版本。安装版启动时及每 6 小时检查 GitHub 上的新版本，发现后显示窗口提示和托盘提醒。点击“更新并重启”才会下载、安装并重新启动；录音、转录、粘贴和模型切换期间不能更新。也可在“常规”的“版本与更新”中手动检查。断网不影响听写，失败后可重试。

设置窗口打开时会显示在任务栏，可右键任务栏图标选择“固定到任务栏”。从便携版迁移后，将原有任务栏固定项取消，再固定安装后的“说”。关闭窗口后仍会定时检查更新。

关闭主窗口后，应用继续在系统托盘运行，不占用任务栏。点击托盘图标可打开设置；右键图标可打开设置、切换转录服务或退出；使用本地服务时，还可在“本地模型”子菜单中切换已下载的模型。当前选择带勾选标记，录音、切换或更新期间禁用切换。需要完全停止应用时，选择“退出”。

转录服务选择会立即自动保存。API Key、地域等配置修改后也会自动保存，停止输入后应用最新配置。豆包使用火山引擎语音控制台的 API Key，默认流式语音识别 2.0 小时版；旧版 App ID、Access Token 和资源 ID 可在展开项中配置。百炼使用阿里云百炼 API Key，地域须与创建 Key 的地域一致，支持北京和新加坡；当前调用模型为 `fun-asr-realtime`。两家凭据分别保存在 Windows 凭据管理器中，切换服务时保留，无需反复填写。清空 API Key 会同步移除保存的 Key；豆包若仍填写旧版 App ID 或 Access Token，会保留这些字段，全部清空后删除整条豆包凭据。云端录音会上传至所选服务，需要联网并按音频时长计费。

豆包听写自动开启语义顺滑、数字规范化（ITN）和标点处理，可清理停顿词、口吃和重复表达。百炼 Fun-ASR 使用模型内置的语气词过滤、ITN 和标点预测。两家的处理均在服务端完成，无需设置。

本地模型加载完成或云端配置就绪后，可在下方共用的“试用听写”卡片中点击输入框，按听写快捷键读出示例，再按一次停止，查看实际识别结果。试用沿用普通听写流程，最终结果会保存到转录历史；设置页只显示配置状态，日常录音状态由浮窗显示。

云端听写时，屏幕底部的单行字幕条随文字长度展开，到达最大宽度后保持不变；新文字出现时平滑左移，让最新内容保持在右侧，没有新文字时停住。蓝点随音量缩放，重音触发波纹，粘贴完成后字幕条收起。字幕条的亚克力背景自动跟随系统亮暗主题，无需重启。选择“本地模型”即可切回本地听写，服务选择自动保存。

在“转录服务”页选择“本地模型”，在模型选择框右侧点击“下载”即可下载约 811 MB 的 Q8_0 模型，不需要安装其他插件。下载可取消，完成后校验文件并刷新列表；空闲且仍使用本地服务时自动选用。检测到已有 Qwen3-ASR-0.6B Q8_0 文件时直接复用并隐藏下载按钮，无需重新下载。打开转录服务页时自动检查模型列表。本地模型列表不再提供 Fun-ASR。模型存放在配置文件旁的 `models` 目录，默认是 `%LOCALAPPDATA%\Shuo\models`。也可继续选择已有 GGUF 模型；加载成功后自动保存，失败时保留原选择。

“文本整理”页的“去掉末尾句号”默认关闭，自动保存并从下一次听写生效。开启后去掉整次输入最后的句号，保留句中标点、问号、感叹号、省略号，以及常见英文缩写等有歧义的句点。此处理在本地完成，不需要额外模型或 API。

“转录历史”按新到旧显示本地模型、豆包和百炼云端完成的转录，保存的是经过排版和文本整理后的最终文字，可选择文字或点击“复制”再次使用。搜索框会在全部记录的文字、日期和服务名称中查找，不区分英文大小写。每次先显示 50 条匹配记录，点击“加载更多”继续查看。记录在粘贴前保存，因此粘贴失败时仍可找回；空结果和未完成的实时文字不会入库。

历史从 0.3.0 起开始记录，保存在当前电脑的 `%LOCALAPPDATA%\Shuo\history.jsonl`，重启和更新程序后保留，不会自动清理或跨电脑同步。文件包含转录文字、完成时间和具体模型名称：本地模型记录文件名（含量化版本），豆包记录识别模型版本和资源 ID，百炼记录云端模型版本，不保存音频。旧记录没有保存具体模型，仍保留原来的服务名称。点击“打开历史文件”可选择 VS Code 等编辑器打开 JSONL 文件，新增记录直接保留中文；读取历史时会移除空行和 JSON 格式空白，并将旧记录的 Unicode 转义转换为中文；转录正文内的空格保持原样，并在同目录保留带唯一后缀的 `.bak` 原文件备份。点击“导出并打开文本”会将全部记录（包括旧版转义记录）写入同目录的 `history.txt`，方便阅读和搜索；每次导出都会更新 TXT 文件，窗口中的搜索条件不影响导出范围。备份时复制 `history.jsonl`。

本地模型在停止录音后转写。云端的实时文字可能修正，只有最终结果会粘贴；连接中断或超时时会提示失败。普通权限应用不能向管理员权限目标粘贴文本。

## 配置

新安装的配置位于 `%LOCALAPPDATA%\Shuo\settings.json`。如果新文件不存在，应用会继续使用已有的 `%LOCALAPPDATA%\WindowsDictation\settings.json`，保留原有快捷键和偏好。两者都不存在时，首次启动服务会优先从 `~/.pi/agent/pi-transcribe.json` 导入配置；没有可导入文件时自动创建默认配置，可直接在界面填写云端服务 API Key。

GGUF 模型不包含在安装包中，可从本地模型卡片直接下载。已有文件的配置方式见[安装指南](docs/setup.md#3-使用已有模型)。

## 开发

需要 Windows、.NET SDK 10、Node.js 22+ 和本地 GGUF 模型。

```powershell
npm ci
dotnet run --project src/Shuo/Shuo.csproj
```

项目结构和进程协议见[开发说明](docs/development.md)。

## 发布

按[安装指南](docs/setup.md#1-在构建电脑生成安装包)构建 x64 安装器。发布标签会在 GitHub Actions 中构建安装器和更新包；安装版从 GitHub Releases 获取更新。
