# shuo

Windows 原生 WinUI 3 应用，提供语音输入、实时字幕和朗读。日常入口按用途划分，模型、地址和凭据集中在“服务设置”。

## 安装与使用

从 [最新 Release](https://github.com/thomjiji/shuo/releases/latest) 下载安装版。当前分支的任务入口界面尚未发布，可按 [开发规则](AGENTS.md) 构建本地预览。

- **语音输入**：在其他应用的输入框中按听写快捷键开始说话，再按一次将文字输入光标处。页面提供独立试用区，试用结果留在页面中。
- **实时字幕**：为电脑播放的声音显示浮窗字幕，选择原文、中文或英文后点击“开启字幕”。字幕语言会记住，快捷键使用相同的语言设置。
- **朗读**：粘贴文字后选择原文朗读或中文译读，也可以在其他应用选中文字，按朗读快捷键直接播放。默认朗读快捷键为 `Ctrl+Alt+Space`，再次按下停止。

原文字幕目前使用 Mac ASR；翻译字幕使用已配置的字幕翻译服务。服务部署和高级配置见下文。关闭窗口后应用仍在托盘运行，右键托盘图标可退出。

听写、字幕和朗读一次运行一项，避免采集自身播报或争用模型。普通权限运行的应用不能向管理员权限窗口输入文字。版本与更新位于“关于”；安装版在用户点击后才下载安装更新。

## 转录服务

“服务设置”按本机模型、自托管 Mac、火山引擎 / 豆包和阿里云百炼分组。地址、模型和凭据修改后点击“保存服务设置”；语音输入在“输入设置”中选择识别服务。云端凭据保存在 Windows 凭据管理器中，切换服务时保留；清空字段并保存会移除对应 Key。豆包分别提供“转录 API”和“朗读 API”，朗读也可共用转录 API。

| 服务 | 配置与处理方式 |
| --- | --- |
| 本地模型 | 使用 Qwen3-ASR-0.6B Q8_0，停止录音后在本机转写，无需联网。 |
| 自托管（MLX） | 在 Apple Silicon Mac 通过 MLX 部署 Qwen3-ASR 1.7B / 0.6B，填写 Mac 的 Tailscale IP 并选择模型，通过 Tailscale 实时识别。[部署说明](docs/selfhosted.md)。 |
| 火山引擎 | 填写语音控制台的转录 API，可选择豆包流式语音识别 2.0 或 1.0，默认使用 2.0 小时版。 |
| 阿里云百炼 | 可选择 `fun-asr-realtime` 或 `qwen3-asr-flash-realtime`，修改后保存服务设置。固定使用北京地域，填写该地域的百炼 API Key。 |

云端录音会上传到所选服务并按音频时长计费。豆包开启语义顺滑、数字规范化（ITN）和标点处理；百炼使用模型内置的语气词过滤、ITN 和标点预测。录音时浮窗显示实时文字，结果可能修正，只有最终文本会粘贴；断线或超时会提示失败。

选择本地服务后，若未检测到 Qwen 模型，点击模型框右侧的“下载”获取约 811 MB 的文件。下载可取消，完成后校验并刷新列表；空闲且仍使用本地服务时自动选用。已有模型可直接复用，打开服务设置页时自动检查列表。模型切换成功后保存，失败时保留原选择。

下载的模型位于配置文件旁的 `models` 目录，默认是 `%LOCALAPPDATA%\Shuo\models`。自行准备 GGUF 文件的方法见[使用已有模型](docs/setup.md#3-使用已有模型)。

## 实时翻译

在“实时字幕 -> 字幕设置”中选择百炼 Qwen3.5 LiveTranslate Flash 或自托管 Mac，即可将系统播放的声音翻译为中文或英文字幕。连接信息在“服务设置”中保存。百炼需要业务空间和 API Key；Mac 使用已有的 Qwen3 ASR 和 Qwen3 8B，只需主机 IP。浮窗提供暂停、停止和关闭按钮。使用方法见[实时翻译说明](docs/translation.md)。

## 实时朗读

在“朗读”中选择“原文朗读”或“中文译读”：前者直接按原文语言播放，后者由 Mac 自动识别英文、日文等原文语言并翻译成中文，再交给豆包 TTS 朗读。两种方式也都可使用自托管 Mac 的 Serena 音色生成语音。[自托管朗读部署](docs/selfhosted-reading.md)。默认快捷键为 `Ctrl+Alt+Space`，选中文字后按下启动，再次按下停止。悬浮条支持暂停、继续、停止和关闭。选区接口不可用时通过临时复制取词，并在没有其他复制操作时恢复原剪贴板。配置及使用限制见[实时朗读说明](docs/reading.md)。

## 文本与历史

“语音输入 -> 输入设置”中的“去掉末尾句号”默认关闭，修改后自动保存，从下一次听写生效。它只去掉整次输入末尾的句号，保留句中标点、问号、感叹号、省略号及英文缩写等有歧义的句点。

“历史”按新到旧显示经过文本整理后的最终文字，可搜索文字、日期和服务名称并复制结果。每次显示 50 条匹配记录，点击“加载更多”继续查看。记录在粘贴前保存，因此粘贴失败仍可找回；空结果和未完成的实时文字不入库。

历史位于 `%LOCALAPPDATA%\Shuo\history.jsonl`，包含文字、完成时间和模型名称，不保存音频。重启和更新后保留，不自动清理或跨电脑同步；备份时复制该文件。“打开历史文件”可用编辑器查看 JSONL，“导出并打开文本”将全部记录写入同目录的 `history.txt`，不受当前搜索条件影响。整理旧版历史格式时会保留 `.bak` 备份。

## 配置文件

新安装的配置位于 `%LOCALAPPDATA%\Shuo\settings.json`。若不存在，则继续使用已有的 `%LOCALAPPDATA%\WindowsDictation\settings.json`。两者都不存在时，首次启动会从 `~/.pi/agent/pi-transcribe.json` 导入已有配置，或创建默认配置。

## 开发与发布

需要 Windows、.NET SDK 10 和 Node.js 22+。本地听写还需 GGUF 模型，也可配置云端服务。

本地预览构建、自动启动和跨平台验证遵循 [AGENTS.md](AGENTS.md)，预览产物统一放在 artifacts/preview/。

项目结构与进程协议见[开发说明](docs/development.md)。按[构建安装包](docs/setup.md#1-在构建电脑生成安装包)生成 x64 安装器；推送版本标签后，GitHub Actions 会构建并发布安装器和应用内更新包。
