# 实时朗读

实时朗读支持“原文朗读”和“中文译读”。原文朗读可选择豆包云端或自托管 Mac，直接按原文语言生成语音。中文译读由 Mac 自动识别英文、日文等原文语言并翻译成中文，默认交给豆包 TTS 2.0 朗读，也可选择完全在 Mac 上生成语音。两种方式共用取文、快捷键和播放器，收到音频后开始播放。

## 开启与使用

1. 在“服务设置”中填写 Mac 地址或豆包凭据并保存。在“朗读 -> 朗读设置”中选择声音服务和音色，点击“保存朗读设置”。快捷键位于朗读页首行，开关修改后立即保存。
2. 选择“原文朗读”或“中文译读”。方式切换会自动保存，快捷键按照当前方式启动。
3. 声音服务选择“豆包”时，在“服务设置 -> 火山引擎 / 豆包”中配置朗读 API，或开启“朗读共用转录 API”；对应项目需要开通语音合成。选择“自托管 Mac”时使用 Mac 语音合成，无需云端凭据。
4. 中文译读先由 Mac 将文字翻译成中文，再使用所选声音服务朗读。选择豆包时，译文完整返回后交给豆包 TTS 2.0；选择自托管 Mac 时，翻译和语音合成都在 Mac 上完成。安装方法见[自托管中文译读](selfhosted-reading.md)。
5. 自托管 Mac 使用 Serena 音色，速度可选 0.85、1、1.15 和 1.3 倍，默认 1 倍。声音服务按朗读方式分别记住；地址在服务设置中共用。
6. 在其他应用中选中文字，松开鼠标后按朗读快捷键，默认是 `Ctrl+Alt+Space`。也可以在朗读页粘贴文字，再点击“朗读”。
7. 播放期间可在悬浮条或朗读页暂停、继续、停止；再次按朗读快捷键也会停止。悬浮条从左到右为声波、暂停/继续、停止、关闭，与实时翻译浮窗底部的控件顺序一致。停止后保留浮窗，暂停和停止按钮变灰；关闭会停止朗读并收起浮窗。正常播放完成后自动收起。切换设置页面不会停止播放。中文译文按生成进度显示，可选中复制，显示位置可能领先于播放进度。

点击快捷键按钮可以录入其他组合。朗读和转录不能设置为同一组合；系统注册失败时会提示冲突并恢复原快捷键。没有能保证在所有电脑上都不冲突的全局快捷键，若其他软件占用，请更换组合。

一次最多接受 30000 个字符。长文优先在段落、句末或词间分段，豆包原文朗读每段最多 1800 个 UTF-8 字节，中文译读及 Mac 原文朗读每段最多 900 个 UTF-8 字节；这些是应用的请求预算。所有音频进入同一个播放器，网络较慢时可能短暂缓冲。短段之间的上下文有限，跨段指代和术语可能不一致，译文仍可能出现遗漏或误译。

暂停会保留播放位置，并阻止下一段请求；当前请求可能继续在服务端生成音频。停止会取消当前请求、后续段落及缓冲播放。悬浮条不显示状态文字，播放和错误状态可在朗读页查看。朗读和听写、系统声音翻译互斥，避免 Shuo 采集自己的播报。

## 文字获取与隐私

Shuo 优先通过 Windows 辅助功能接口获取前台选区。接口没有返回文字时，会临时发送一次 `Ctrl+C`，只读取这次操作产生的新文本，不朗读原有剪贴板内容。此方式适用于支持系统复制的编辑器、网页和其他应用，无需安装编辑器插件或开启屏幕阅读器模式。

复制前会暂存剪贴板的各个格式，读取后恢复；如果期间出现新的复制操作，则保留新内容。无法完整暂存原剪贴板时，本次不会执行复制。临时复制仍可能被系统或第三方剪贴板历史记录保存。

没有复制结果、识别到密码输入框或复制结果明确标记为空选区时，不启动合成。部分编辑器在没有选区时会复制整行，Shuo 会检查复制结果提供的空选区标记；若应用既不提供可靠选区信息，也不标记整行复制，无法完全区分该行为与真正的选区。使用前应确认已选中文字。管理员权限窗口可能拒绝普通权限进程发送的复制操作。

原文朗读按所选服务将文字发送到火山引擎或自己的 Mac。中文译读将原文发送到自己的 Mac；选择豆包声音服务时还会将完成的中文译文发送到火山引擎生成语音。自托管服务失败时不会自动切换到云端。Shuo 不将朗读原文、译文或生成音频写入历史或文件；原文和译文只在本次窗口中保留，退出后不恢复。Key 保存到 Windows 凭据管理器。停止不能撤回已发送的内容，也不能免除云端已经生成的音频费用。读取或服务失败的具体原因会在朗读页和选区操作的浮窗中提示。
