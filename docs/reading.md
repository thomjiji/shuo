# 实时朗读

实时朗读把选中文字、剪贴板文字或手动粘贴的段落发送到豆包语音合成 2.0，收到音频后开始播放。支持系统音色、语速调整、暂停、继续和停止。

## 开启与使用

1. 打开 Shuo 的“实时朗读”，开启功能。默认使用“转录服务”中配置的火山引擎语音 API Key；也可以关闭复用并填写单独的 Key。对应项目需要开通语音合成服务，已有识别权限不代表已开通合成。
2. 保留默认的 vv 音色，点击“保存朗读设置”。需要其他声音时，在官方音色列表中选择语音合成 2.0 音色，将其 ID 填入后保存。
3. 在其他应用中选中文字，按 `Ctrl+Alt+R` 开始朗读。若应用不提供选区，先复制，再按 `Ctrl+Alt+Shift+R` 朗读剪贴板。也可以在 Shuo 的试用框中粘贴文字并点击“朗读文字”。
4. 播放期间可在朗读页暂停、继续或停止；再次按任一朗读快捷键、按听写快捷键或关闭朗读浮窗也会停止。

朗读和听写、系统声音翻译互斥，避免 Shuo 采集自己的播报。切换设置页面不会停止播放。快捷键被其他程序占用时会提示注册失败，可继续使用页面按钮。当前一次最多接受 30000 个字符，按小段依次合成，调整语速从下一次朗读生效。

## 文字获取与隐私

选区通过 Windows 辅助功能接口读取，不模拟复制，不改写剪贴板。不支持该接口的应用、密码输入框和超时的选区读取不会自动回退到旧剪贴板。剪贴板只在用户主动触发对应操作时读取一次，不监听变化，不读取历史。

朗读文字会发送到火山引擎云端处理，Shuo 不将朗读原文和生成音频写入历史或文件。手动粘贴的文字在本次窗口中保留，退出后不恢复。单独配置的 Key 保存到 Windows 凭据管理器。停止会取消后续处理，但不能撤回已发送的内容；服务商侧的数据处理规则以其协议为准。

## 服务选择

原型先接豆包，主要考虑 Shuo 已有火山引擎语音凭据配置，以及豆包支持整段文字输入、音频流式输出，适合选区朗读。百炼也提供流式语音合成；仅凭官方能力说明不能判断豆包听感一定更好。[豆包语音合成说明](https://www.volcengine.com/docs/6561/1257543)、[百炼实时语音合成](https://help.aliyun.com/zh/model-studio/realtime-tts-user-guide)。

比较听感时，应使用相同的中文长段落、中英混排、英文原文和数字日期；记录从触发到首个声音的时间，并听完整段落，检查漏读、重复、停顿及长时间听读是否舒服。
