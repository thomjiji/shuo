# 实时朗读

实时朗读支持“原文朗读”和“中文译读”。原文朗读可选择豆包云端或自托管 Mac，直接按原文语言生成语音；中文译读可选择千问云端或自托管 Mac，自动识别英文、日文等原文语言，翻译成中文再朗读。千问使用 Tina 音色，Mac 使用 Serena 音色。两种方式共用取文、快捷键和播放器，收到音频后开始播放。

## 开启与使用

1. 打开 Shuo 的“实时朗读”，开启功能并保存设置。
2. 选择“原文朗读”或“中文译读”。方式切换会自动保存，快捷键按照当前方式启动。
3. 原文朗读选择“豆包云端”时，默认复用“转录服务”中的火山引擎语音 API Key，也可以单独配置；对应项目需要开通语音合成服务。选择“自托管 Mac（Serena）”时无需 API Key，文字直接交给 Mac 语音模型，不经过翻译。原文朗读和中文译读的后端选择分别保存，Mac 地址和播放速度共用。豆包的音色和语速只影响豆包原文朗读。
4. 中文译读选择“千问云端”时，使用“实时翻译”页面中的百炼业务空间和 API Key，需要有 Omni 模型权限，不必开启系统声音实时翻译。云端语速可选慢速、正常、稍快和快速，默认稍快；档位控制模型的朗读节奏，不是精确倍速。选择“自托管 Mac（Serena）”时，填写 Mac 的 Tailscale IP，点击“测试 Mac 连接”；翻译和语音均在 Mac 上生成，无需云端凭据。本地速度可选 0.85、1、1.15 和 1.3 倍，默认 1 倍。服务与速度选择自动保存，下次朗读生效。安装方法见[自托管中文译读](selfhosted-reading.md)。
5. 在其他应用中选中文字，松开鼠标后按朗读快捷键，默认是 `Ctrl+Alt+Space`。也可以在朗读页粘贴文字，再点击“原文朗读”或“中文译读”。
6. 播放期间可在悬浮条或朗读页暂停、继续、停止；再次按朗读快捷键也会停止。悬浮条从左到右为声波、暂停/继续、停止、关闭，与实时翻译浮窗底部的控件顺序一致。停止后保留浮窗，暂停和停止按钮变灰；关闭会停止朗读并收起浮窗。正常播放完成后自动收起。切换设置页面不会停止播放。中文译文按生成进度显示，可选中复制，显示位置可能领先于播放进度。

点击快捷键按钮可以录入其他组合。朗读和转录不能设置为同一组合；系统注册失败时会提示冲突并恢复原快捷键。没有能保证在所有电脑上都不冲突的全局快捷键，若其他软件占用，请更换组合。

一次最多接受 30000 个字符。长文优先在段落、句末或词间分段，豆包原文朗读每段最多 1800 个 UTF-8 字节，中文译读及 Mac 原文朗读每段最多 900 个 UTF-8 字节；这些是应用的请求预算。所有音频进入同一个播放器，网络较慢时可能短暂缓冲。短段之间的上下文有限，跨段指代和术语可能不一致，译文仍可能出现遗漏或误译。

暂停会保留播放位置，并阻止下一段请求；当前请求可能继续在服务端生成音频。停止会取消当前请求、后续段落及缓冲播放。悬浮条不显示状态文字，详细状态和已请求段数可在朗读页查看，已请求不代表已播放。朗读和听写、系统声音翻译互斥，避免 Shuo 采集自己的播报。

## 文字获取与隐私

Shuo 优先通过 Windows 辅助功能接口获取前台选区。接口没有返回文字时，会临时发送一次 `Ctrl+C`，只读取这次操作产生的新文本，不朗读原有剪贴板内容。此方式适用于支持系统复制的编辑器、网页和其他应用，无需安装编辑器插件或开启屏幕阅读器模式。

复制前会暂存剪贴板的各个格式，读取后恢复；如果期间出现新的复制操作，则保留新内容。无法完整暂存原剪贴板时，本次不会执行复制。临时复制仍可能被系统或第三方剪贴板历史记录保存。

没有复制结果、识别到密码输入框或复制结果明确标记为空选区时，不启动合成。部分编辑器在没有选区时会复制整行，Shuo 会检查复制结果提供的空选区标记；若应用既不提供可靠选区信息，也不标记整行复制，无法完全区分该行为与真正的选区。使用前应确认已选中文字。管理员权限窗口可能拒绝普通权限进程发送的复制操作。

原文朗读将文字发送到火山引擎；中文译读按所选服务将原文发送到阿里云百炼或自己的 Mac。自托管服务失败时不会自动切换到云端。Shuo 不将朗读原文、译文或生成音频写入历史或文件；原文和译文只在本次窗口中保留，退出后不恢复。Key 保存到 Windows 凭据管理器。停止不能撤回已发送的内容，也不能免除云端已经生成的音频费用。读取或服务失败的具体原因会在朗读页和选区操作的浮窗中提示。
