# 实时朗读

实时朗读把选中文字或手动输入的段落发送到豆包语音合成 2.0，收到音频后连续播放。支持系统音色、语速调整、暂停、继续和停止。浮窗只显示状态指示器：准备和缓冲时显示加载状态，播放时波纹随音量变化，暂停时停止音量波动。

## 开启与使用

1. 打开 Shuo 的“实时朗读”，开启功能。默认使用“转录服务”中配置的火山引擎语音 API Key；也可以关闭复用并填写单独的 Key。对应项目需要开通语音合成服务，已有识别权限不代表已开通合成。
2. 从下拉菜单选择音色，点击“保存朗读设置”。
3. 默认快捷键为 `Ctrl+Alt+Space`，已有配置以页面显示为准。在其他应用中选中文字，松开鼠标后按快捷键朗读。也可以在试用框中输入文字并点击“朗读文字”。
4. 播放期间可在朗读页暂停、继续或停止；再次按朗读快捷键也会停止。切换设置页面不会停止播放。

点击快捷键按钮可以录入其他组合。朗读和转录不能设置为同一组合；系统注册失败时会提示冲突并恢复原快捷键。没有能保证在所有电脑上都不冲突的全局快捷键，若其他软件占用，请更换组合。

当前应用每次请求最多发送 1800 个 UTF-8 字节；这是应用的请求预算，并非已确认的服务硬上限。文本在预算内时完整发送；超出时，在预算内最后一个段落结束处切分，保留原有换行。单个段落本身超限时优先按句末切分；没有句末标点时按完整 Unicode 字符切分。所有返回音频进入同一个播放器，网络较慢时可能短暂缓冲。一次最多接受 30000 个字符；调整语速从下一次朗读生效。朗读和听写、系统声音翻译互斥，避免 Shuo 采集自己的播报。

## 文字获取与隐私

Shuo 优先通过 Windows 辅助功能接口获取前台选区。接口没有返回文字时，会临时发送一次 `Ctrl+C`，只读取这次操作产生的新文本，不朗读原有剪贴板内容。此方式适用于支持系统复制的编辑器、网页和其他应用，无需安装编辑器插件或开启屏幕阅读器模式。

复制前会暂存剪贴板的各个格式，读取后恢复；如果期间出现新的复制操作，则保留新内容。无法完整暂存原剪贴板时，本次不会执行复制。临时复制仍可能被系统或第三方剪贴板历史记录保存。

没有复制结果、识别到密码输入框或复制结果明确标记为空选区时，不启动合成。部分编辑器在没有选区时会复制整行，Shuo 会检查复制结果提供的空选区标记；若应用既不提供可靠选区信息，也不标记整行复制，无法完全区分该行为与真正的选区。使用前应确认已选中文字。管理员权限窗口可能拒绝普通权限进程发送的复制操作。

Shuo 不将朗读原文和生成音频写入历史或文件。手动输入的文字在本次窗口中保留，退出后不恢复。单独配置的 Key 保存到 Windows 凭据管理器。停止会取消后续处理，但不能撤回已发送到火山引擎的内容。读取失败的具体原因可在朗读页查看，或悬停状态指示器查看提示。
