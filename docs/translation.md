# 实时翻译

Shuo 翻译默认播放设备的声音，在浮窗中显示中文或英文字幕。可选择百炼 Qwen3.5 LiveTranslate Flash，或自托管 Mac 上的 Qwen3 ASR + Qwen3 8B。两种后端都自动识别源语言。此功能目前为试用功能。

## 开始使用

1. 在“实时翻译”中选择“千问云端”或“本地 Mac”，展开“设置”启用翻译并填写连接信息。千问云端需要北京地域的业务空间 ID（Workspace ID）和可调用模型的 API Key；本地 Mac 只需填写 Mac 的 Tailscale 主机 IP。快捷键也在“设置”中修改。
2. 使用 Mac 时，先运行[自托管转录服务](selfhosted.md)和[译读服务](selfhosted-reading.md)，并允许 Windows 访问 Mac 的 TCP 18765、18766 端口。已部署译读服务的用户需要用当前版本执行一次 `up`，以安装纯文字翻译接口。
3. 选择字幕语言，点击“开始翻译”。连接成功后播放视频或其他音频。
4. 使用浮窗底部的暂停/继续、停止、关闭按钮控制翻译。页面按钮或翻译快捷键也可以停止；停止后保留字幕，关闭则停止并收起浮窗。

点击开始时保存翻译设置。百炼 API Key 独立保存在 Windows 凭据管理器中，后端、主机地址和字幕语言等选项保存在配置文件的 `translation` 节点。Mac 后端无需云端凭据，不会在连接失败时自动改用百炼。

需要有权调用该模型的百炼 API Key；地域、业务空间和凭据必须匹配。业务空间 ID 可在百炼控制台查看，详见[官方接入说明](https://www.alibabacloud.com/help/zh/model-studio/qwen3-5-livetranslate-flash-realtime)。

## 字幕与音频

字幕浮窗上方固定显示两行，文字达到宽度后自动换行，新行出现时最上面一行移出。下方从左到右为声波、暂停/继续、停止、关闭，与朗读浮窗的控件顺序一致。拖动空白处可移动浮窗，字幕更新时保持位置不变。暂停时冻结字幕并丢弃新采集的声音，连接保持在线；恢复后继续显示结果。停止时先结束采集，再等待最后一段译文，百炼最长等待 20 秒，Mac 最长等待 60 秒；暂停和停止按钮变灰，关闭按钮仍可收起浮窗。

百炼只显示已确认的译文，临时预测文字不会显示；服务端以 500 毫秒静音判定语音结束。Mac 先识别声音，再把最近一段文字交给 Qwen3 翻译；字幕可能随识别修订而更新。每次最多翻译最近 900 个 UTF-8 字节，处理跟不上时合并中间快照以优先追上当前声音，不保存完整会话记录。Mac ASR 单次会话最多 30 分钟，超过后需要重新开始。

配置了 autocorrect 时，译文在显示前会自动整理中英文、数字之间的空格；格式化失败或超时则显示未整理的译文。首条字幕延迟取决于网络、语音内容和模型处理速度，不保证固定秒数。翻译只用于浮窗显示，不自动粘贴或写入转录历史。

采集范围是默认播放设备的全部声音，包括该设备上其他应用的提示音和人声。切换播放设备后，请停止并重新开始翻译。翻译期间不能同时使用 Shuo 听写或朗读。

系统音频以 16 kHz、单声道、16 位 PCM 发送到所选后端：百炼在北京地域处理，按模型计费规则收费；Mac 在用户自己的设备上完成识别和翻译，无需生成朗读音频。应用不保存音频文件，也不发送屏幕画面。

## 开发验证

```powershell
dotnet run --project test/Translation.Tests
dotnet build src/Shuo/Shuo.csproj -p:Platform=x64
```

测试覆盖云端已确认字幕、本地识别快照修订、音频传输、目标语言、字幕长度限制、地址校验、会话错误及停止后尾句返回。

真实 Mac 测试将指定的 16 kHz 单声道 PCM 文件按实时速度发送到已部署的服务，并输出英文字幕：

```powershell
dotnet run --project test/Translation.Tests -- --self-hosted <MacIP> <audio.pcm> en
```

真实调用测试读取本机已保存的凭据，将指定的 16 kHz 单声道 PCM 文件按实时速度发送到百炼，并输出中文译文和首条字幕耗时。该命令会保存所填的翻译地域和业务空间，并产生 API 调用费用：

```powershell
dotnet run --project test/Translation.Tests -- --live cn-beijing <WorkspaceID> <audio.pcm>
```
