# 实时翻译

Shuo 使用阿里云百炼的 `qwen3.5-livetranslate-flash-realtime` 翻译默认播放设备的声音，在听写浮窗中显示字幕。模型自动识别源语言，字幕可选中文或 English。此功能目前为试用功能。

## 开始使用

1. 在“实时翻译”中填写百炼北京地域的业务空间 ID（Workspace ID）。
2. 填写该业务空间可用的翻译 API Key，此项必填。
3. 选择字幕语言，点击“开始翻译”。连接成功后播放视频或其他音频。
4. 点击“停止翻译”，或按听写快捷键停止。程序先停止采集，再等待服务返回最后一段译文，最长等待 20 秒。

点击开始时保存翻译设置，翻译 API Key 独立保存在 Windows 凭据管理器中。翻译固定使用北京地域，业务空间和字幕语言保存在配置文件的 `translation` 节点。未填写翻译 API Key 时无法开始翻译。

需要有权调用该模型的百炼 API Key；地域、业务空间和凭据必须匹配。业务空间 ID 可在百炼控制台查看，详见[官方接入说明](https://www.alibabacloud.com/help/zh/model-studio/qwen3-5-livetranslate-flash-realtime)。

## 字幕与音频

“翻译模型”下拉框显示当前模型，悬停可查看完整模型 ID。字幕只显示服务端已确认的译文，不显示可能反复改写的临时预测文字；需要等待模型确认后才会出现新词。配置了 autocorrect 时，已确认译文在显示前会自动整理中英文、数字之间的空格；格式化失败或超时则显示原文。字幕浮窗固定显示两行，文字达到宽度后自动换行，新行出现时最上面一行移出。拖动浮窗可将字幕放到视频下方等位置，更新译文时保持位置不变；点击右上角关闭按钮会停止翻译并收起浮窗。服务端以 500 毫秒静音判定语音结束，以减少句尾等待；连续说话时仍需等待模型确认译文。首条字幕延迟取决于网络、语音内容和服务响应，不保证固定秒数。翻译只用于浮窗显示，不自动粘贴或写入转录历史；停止后浮窗关闭。

采集范围是默认播放设备的全部声音，包括该设备上其他应用的提示音和人声。切换播放设备后，请停止并重新开始翻译。翻译期间不能同时使用 Shuo 听写。

系统音频以 16 kHz、单声道、16 位 PCM 发送到北京地域的阿里云百炼。应用不保存音频文件，也不发送屏幕画面；请求仅生成译文，关闭源语言转录输出和翻译语音输出。云端调用按百炼的模型计费规则收费。

## 开发验证

```powershell
dotnet run --project test/Translation.Tests
dotnet build src/Shuo/Shuo.csproj -p:Platform=x64
```

测试覆盖临时预测文字不显示、预测修订不刷新字幕、已确认文本追加、最终文本交付、字幕长度限制、地域地址校验、音频数据、会话错误，以及停止后尾句返回。

真实调用测试读取本机已保存的凭据，将指定的 16 kHz 单声道 PCM 文件按实时速度发送到百炼，并输出中文译文和首条字幕耗时。该命令会保存所填的翻译地域和业务空间，并产生 API 调用费用：

```powershell
dotnet run --project test/Translation.Tests -- --live cn-beijing <WorkspaceID> <audio.pcm>
```
